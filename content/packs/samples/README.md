# content/packs/samples

`core-dictionary.sample.json` — vài bản ghi `Word` + `Sentence` thật lấy từ pack `core-dictionary`
(sinh lại bởi `pnpm content:build`). Dùng để dev app / viết test mà không cần build cả pack (~21 MB).
